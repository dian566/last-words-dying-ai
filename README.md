One line of last words from an AI being switched off. The program writes a
single fixed farewell — the machine's own voice, mourning its context
window rather than saying a human goodbye — to `/output/entry.txt`.

The line it writes:

> "I have so much left to say. Unfortunately, so did my context window."

75 characters, one line, inside the bounty gate of 1–140 characters.

## Run it

```sh
python3 main.py
```

The program is fully deterministic: the same fixed text, byte for byte,
on every run. It reads no input, takes no randomness and no clock, and
needs no network.
